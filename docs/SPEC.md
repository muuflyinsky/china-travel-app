# China Travel Buddy — 产品规格说明（Spec）

> 版本：v0.3 原型 · 最后更新：2026-10-23 · 代码仓库：`muuflyinsky/china-travel-app`（`main` 分支）
> 本文描述**当前代码实际实现的行为**，以及已知限制和待决问题。评审时请对照代码；文中“未验证”的条目代表还没有在真机或真实 Key 下测过。

---

## 1. 产品概述

**一句话**：帮外国游客在中国“吃得安心、走得明白、付得出钱、住得进去”的手机网页 App（PWA）。

**目标用户**
| 用户 | 场景 | 核心诉求 |
|---|---|---|
| 首次来华的外国游客（主力） | 出发前 2–4 周 + 在华 3–14 天 | 签证/支付/上网准备；看懂菜单；不迷路；订酒店和火车 |
| 有食物过敏或宗教饮食限制的游客 | 每顿饭 | 不吃错东西，能跟服务员说清楚 |
| 商务/长住外国人（次要） | 在华 | 翻译、支付、打车 |

**不做的事（当前范围外）**：机票酒店自营交易、用户账号体系、社区 UGC、离线地图、中国手机号/实名代办。

**商业模式**：OTA / eSIM 联盟佣金（主），后续可加会员和 B 端多语言菜单。

---

## 2. 信息架构

底部 5 个主标签（iOS 规范 2–5 个）+ 若干二级页面（带“返回”）。

```
Today（首页）  Eat（菜单）  Go（出行）  Stay（住宿）  Talk（翻译）
   │
   ├─ ⚙ Settings（设置）          /settings   —— 每个主页面右上角齿轮进入
   ├─ Pay（支付）                 /pay
   ├─ Mobile data（上网 / eSIM）  /esim
   ├─ Before you go（出发前准备）/prepare
   └─ Emergency（紧急求助）       /sos
```
旧地址 `/essentials` 会自动重定向到 `/prepare`。

### 2.1 两种模式
首次打开首页会问“你在准备行程，还是已经在中国？”，答案存为 `profile.mode`：
- **planning（准备中）**：首页显示到达倒计时 + 6 项准备清单（签证、支付、上网、App、订票、过敏）+ 试用菜单入口。
- **in_china（在中国）**：首页显示所在城市、拍菜单、Where to?、天气、支付快捷按钮、**停留倒计时**、给人看的卡片（打车卡、过敏卡、紧急）。不再显示签证政策。

首页顶部有分段切换，设置页里也能改。

## 3. 功能规格

每项给出：用户能做什么 → 实现方式 → 验收标准 → 已知限制。

### 3.1 Eat · 菜单识别（核心功能）
- **输入**：拍照（手机摄像头 `capture=environment`），或手动输入/粘贴菜名。
- **处理**：照片在手机端压缩到最长边 1600px（JPEG 0.85），发到 `/api/menu`，由大模型返回结构化 JSON（`lib/llm.ts` 中的 `MenuSchema`）。请求带上：目标语言、当前城市（让模型按当地做法推断，如川菜和粤菜版本不同）。
- **每道菜输出**：中文原名、拼音、翻译名、字面意思、描述、分类、价格、配料（标注“菜单上写的”还是“按标准做法推断”）、过敏原（欧盟 14 类 + 味精）、肉类类型、是否素食、是否含酒、辣度 0–3、置信度、备注。
- **个性化**：与用户设置的过敏原/饮食限制比对，冲突的菜红框 + 红色警告条；“只看我能吃的”筛选；菜价旁显示换算后的本国货币。
- **给服务员看**：
  - “点这道菜”大字卡：`我要点：X`，加上“请不要放：<你的过敏原>”。
  - 底部常驻“出示过敏卡”按钮：完整中文过敏/饮食说明（`lib/allergens.ts` 的 `staffCardZh`），可朗读。
- **验收**：一份 15 道菜的清晰菜单 40 秒内返回；每道菜都有翻译、拼音和至少 3 个配料；用户过敏原命中时必须标红。
- **已知限制**：配料是推断，不保证准确，页面有免责提示；模型未在真实菜单上做系统评测（见 §9）。

### 3.2 Go · 出行
- 地点搜索（英文、拼音、中文），范围是当前城市（`city.a` 行政区划代码）。
- 定位：浏览器 GPS（WGS-84）在服务端转为 GCJ-02 坐标（`lib/coords.ts`），再由高德逆地理编码得到城市；不转换的话会偏移 300–700 米。
- 路线：同时请求高德公交/地铁、步行、驾车三种，返回结构化步骤（`RouteStep`），前端按用户语言拼出文字（“徒歩 350m”、“Metro Line 2: A → B (3 stops)”），下面附中文原文。
- 附近：地铁、厕所、药店、ATM、便利店、医院（5km 内，按距离排序）。
- 打车卡：“师傅您好，请带我去：<名称> <地址>”，大字全屏 + 中文朗读。
- 一键跳转高德 / 苹果地图导航（GCJ-02 坐标）。
- **已知限制**：定位被拒绝时只能搜索、看不到路线；滴滴没有公开的外部跳转链接，只能引导到 App 商店。

### 3.3 Stay · 住宿
- 城市选择器、入住/离店日期、人数、附近地标。
- “在 Trip.com 搜酒店”（主，金色按钮）/“在飞猪搜”（次，仅中文用户）。
- 高德酒店 POI 列表：名称、拼音、评分、参考价（同时显示 ¥ 和本国货币）、“查价格”（Trip.com 关键词搜索）、地图。
- 提示：外国人入住需护照，部分民宿无法接待外宾。

### 3.4 Talk · 翻译
- 双向翻译（用户语言 ↔ 中文），支持语音输入（Web Speech API）和朗读；中文结果附拼音；可全屏展示。
- 离线短语本：5 类 28 句，中文 + 拼音 + 用户语言释义，可朗读、可全屏。

### 3.5 Pay · 支付
- 一键打开：支付宝付款码（`alipays://platformapi/startapp?appId=20000056`）、支付宝扫一扫（`saId=10000007`）、微信（`weixin://`，微信不开放直接打开扫码页）。1.6 秒内没有离开页面就视为没装，自动跳 App Store / Google Play。
- 价格换算：输入 ¥ 金额 → 约合本国货币；超过 ¥200 时同时显示含约 3% 外卡手续费的金额。
- 支付宝 / 微信绑卡步骤、手续费说明、建议带少量现金。
- **未验证**：跳转链接未在真机测试；手续费规则以支付宝最新公告为准。

### 3.6 Mobile data · eSIM
- 6 家服务商：Holafly（无限流量）、Airalo、Saily、Nomad、Trip.com、Klook，每家显示图标、卖点标签和“查看中国套餐”按钮（经 `/api/go` 统计后跳转）。
- 说明漫游 eSIM 可正常使用 Google / WhatsApp，以及机场办本地 SIM 的利弊。

### 3.7 Before you go · 出发前准备
签证与入境（30 天免签、240 小时过境、线上入境卡、官网链接）、支付和上网入口、6 个必装 App（图标 + 商店链接）、火车/机票/景点门票（Trip.com 联盟）、注意事项。

### 3.8 停留倒计时（在华模式）
- 输入：入境日期、入境方式（免签 30 天 / 240 小时过境 / 签证 N 天）。
- 规则：停留期从**入境次日 0 时**起算，最后一天 = 入境日 + N 天（`lib/stay.ts`）。
- 输出：第几天 / 最晚离境日期 / 剩余天数（≤3 天标红，超期给警告）；“加入日历”生成 `.ics` 文件，提前 3 天和当天各提醒一次。
- **待确认**：起算规则需对照国家移民管理局原文再核对一次（§10）。

### 3.9 Settings · 设置
语言、本国货币、模式、到达日期、入境日期/方式/签证天数、过敏原（15 项）、饮食限制（7 项）。**只存在手机本地（localStorage），不上传服务器。**

### 3.10 Emergency · 紧急求助
110 / 120 / 119 / 122 / 12345 一键拨号；“我需要帮助”中文全屏卡；附近医院；护照丢失处理步骤。

## 4. 全国城市支持
- `lib/data/cities.json`：2,213 个地点（369 个地级市 + 县级市/县），含行政区划代码、英文名、拼音、所属省、上级城市。由 `scripts/build-cities.mjs` 从 `china-division` 数据集生成（处理了民族自治州名称，常用英文名用通行写法，如 Harbin、Kashgar）。
- 城市选择器：英文/拼音/中文搜索，热门目的地排前（搜 “wuyuan” 先出江西婺源）。
- 当前城市全局共享（`components/useCity.ts`）：天气、搜索、附近、酒店、出发城市、景点门票、菜单推断都跟着它走；已授权定位时自动识别。

## 5. 多语言
- **界面**：英语、西班牙语、法语、德语、日语、韩语（`lib/i18n/*.ts`，TypeScript 强制每种语言字段齐全）。切换后所有页面即时生效。
- **菜单识别与翻译输出**：15 种语言（`lib/languages.ts`）。界面不支持的语言自动用英文界面。
- **展示给中国人看的内容**一律是中文。

## 6. 技术架构

| 层 | 选型 |
|---|---|
| 框架 | Next.js 16（App Router）+ React 19 + TypeScript |
| UI | Tailwind CSS 4 + Konsta UI（iOS 主题）+ lucide 图标；自建布局组件 `components/ui.tsx` |
| 设计 | 「青花瓷」配色（`docs/design/COLOR_RESEARCH.md`）：钴蓝 #2B4ACB 用于操作，灯笼金 #F2B705 只给预订按钮，红/绿/琥珀只用于过敏警告 |
| 大模型 | Anthropic Claude（`lib/llm.ts`，结构化输出），模型可通过 `CLAUDE_MODEL` 配置 |
| 地图 | 高德 Web 服务 API v3/v5（`lib/amap.ts`） |
| 部署 | Vercel（`vercel.json` 固定香港 `hkg1`）或 Docker（`Dockerfile`，standalone 输出） |
| 数据存储 | 无数据库。用户数据在浏览器 localStorage；点击日志写 `data/clicks.jsonl`（Vercel 上只进日志） |

### 6.1 API 一览
| 路由 | 作用 |
|---|---|
| `POST /api/menu` | 菜单照片/菜名 → 结构化菜单 |
| `POST /api/translate` | 文本翻译 + 拼音 |
| `GET /api/places` | 高德 POI 搜索（城市内或周边） |
| `GET /api/route` | 公交/步行/驾车路线 |
| `GET /api/regeo` | GPS（WGS-84）→ GCJ-02 + 城市信息 |
| `GET /api/weather` | 4 天天气预报 |
| `GET /api/fx` | 汇率（欧洲央行参考汇率；取不到时用内置近似值） |
| `GET /api/go` | 联盟跳转：生成带佣金参数的链接并记录点击 |
| `GET /api/app-icon/[id]` | 从 App Store 获取并缓存 App 图标（`?store=1` 跳转商店页） |
| `GET /api/status` | 哪些 Key 已配置（前端用来显示“示例数据”提示） |

### 6.2 演示模式
未配置 `ANTHROPIC_API_KEY` / `AMAP_KEY` 时，对应接口返回上海的示例数据，前端显示“Sample data”提示。

## 7. 第三方集成与环境变量

| 变量 | 用途 | 必需 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 菜单识别、翻译 | 真实菜单必需 |
| `CLAUDE_MODEL` | 模型选择（默认 `claude-opus-5-5`；`claude-sonnet-5-5` 约半价；`claude-haiku-5-5` 约 1/40） | 否 |
| `AMAP_KEY` | 高德 Web 服务 Key | 真实地图必需 |
| `TRIP_ALLIANCE_ID` / `TRIP_SID` / `TRIP_SUB3` | Trip.com 联盟参数 | 佣金必需 |
| `TRIP_HOST` | Trip.com 站点（默认 `www.trip.com`） | 否 |
| `FLIGGY_PID` | 淘宝联盟 PID（飞猪） | 否 |
| `ESIM_<供应商>_URL` | 各 eSIM 联盟推广链接（AIRALO / HOLAFLY / SAILY / NOMAD / KLOOK） | 否，未填则无佣金 |

### 7.1 联盟跳转流程
```
用户点“查价格” → /api/go?partner=trip&kind=hotel_search&…
  → 服务器拼出 Trip.com 链接，带上 Allianceid、SID、trip_sub3，以及本次点击编号 trip_sub1
  → 记录点击（时间、来源页面、城市、日期、点击编号）
  → 302 跳转到 Trip.com
```
`trip_sub1` 会出现在 Trip.com 后台的订单报表里，可以逐笔对账。只允许跳到白名单内的合作方，不存在开放跳转漏洞。

## 8. 合规与隐私（当前做法 + 风险）
- **服务器在境外**（香港/新加坡）：不需要 ICP 备案；但《个人信息保护法》第 3、53 条和《生成式人工智能服务管理暂行办法》第 20 条仍可能适用，主要风险是域名被拦截。详见 `BRAINSTORM.md` §三。
- **Anthropic 使用政策**：Anthropic 不向中国大陆提供服务，并且限制由中国公司持股超过 50% 的企业使用。运营主体是否适用需要确认（§10）。
- **敏感个人信息**：过敏史属于健康信息，目前只存本地、不上传。上线前需要隐私政策和单独同意。
- **地图**：只调用高德接口并跳转高德/苹果地图，不在 App 内自绘底图，因此不涉及审图号问题。

## 10. 待决问题（需要产品负责人决定）
1. **模型方案**：继续用 Claude，还是改成“千问识图 + DeepSeek 整理”的国产组合（取决于运营主体与合规，见 §8）？
2. **停留天数算法**：“入境次日 0 时起算”需对照移民局官方原文确认。
3. **携程中文站**：是否接入（目前只接了 Trip.com 国际站和飞猪）？
4. **城市本地规则**：热门城市是否人工整理“地铁可否刷外卡”“景点预约方式”等本地信息？
5. **点击日志**：接哪种数据库或分析工具做佣金对账？
6. **域名**：需要自有域名以避免 `*.vercel.app` 在大陆被拦截。
