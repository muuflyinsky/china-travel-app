## 1. Design Tokens（`app/globals.css`、`components/ui.tsx`）

原有颜色和字号 token 不变，新增形状、间距和层级 token，组件里只用这些名字：

| Token | 值 | Tailwind 类 | 用途 |
|---|---|---|---|
| `--radius-card` | 16px | `rounded-card` | 卡片、分组列表、磁贴 |
| `--radius-control` | 12px | `rounded-control` | 按钮、输入框、卡内控件 |
| `--spacing-section` | 24px（原 32） | `mt-section` | 区块之间 |
| `--spacing-stack` | 12px | `space-y-stack` / `gap-stack` | 区块内部 |
| `--spacing-card` / `--spacing-gutter` | 16px | `p-card` / `px-gutter` | 卡片内边距 / 屏幕边距 |
| `--spacing-control` | 48px | `min-h-control` | 主按钮 |
| `--spacing-touch` | 44px | `min-h-touch` / `w-touch` | 所有其他可点元素（HIG 最小值） |
| `--shadow-float` / `--shadow-bar` | — | `shadow-float` / `shadow-bar` | 悬浮在 Tab 栏上的按钮 / Tab 栏 |
| `--tabbar-h` | `80px + safe-area-bottom` | — | 内容底部留白、`.sticky-bottom` 的位置都从它算 |

新增的共享组件：`SectionTitle`（唯一的区块标题样式）、`IconButton`（44px 圆形图标按钮，强制带 label）、`Disclosure`（次级内容折叠）、`EmptyState`（无结果：原因 + 下一步）；`Button` 新增 `outline` 变体。新增工具类：`.chip-row`（横向滚动的筛选行，右侧渐隐提示还有内容）、`.status-scrim`（状态栏遮罩）、`.sticky-spacer`。

全局统一：所有按钮圆角从 16px 改为 12px（卡片保持 16px）；硬编码的 `rounded-2xl` / `rounded-xl` / `min-h-12` 全部换成 token，涉及 Settings、VisaCheck 等共用组件，只改了数值名，按钮之外视觉不变。

**顶部留白**：一级页面不再用 Konsta 的“44px 导航栏 + 52px 大标题”两行结构，改为大标题和设置按钮同一行（App Store 式），随内容滚走，状态栏区域加半透明模糊遮罩。内容起点从 120px 提到约 64px，五个页面都上移约 56px。二级页面（Settings、SOS 等带返回的）仍用标准 iOS 导航栏。

## 2. 各页面

### Today：主要操作 / 快捷操作 / 旅行必备
- **主要操作**：「扫菜单」改为整行主卡片，并直接显示将要检查的过敏原（例如“花生（严重）、甲壳类”），没设置时提示去添加。
- **快捷操作**：「给司机看」和「今天」两个磁贴（高度 132→108px）；支付压缩成一行：支付宝付款码 · 微信支付 · 价格换算图标，仍然一键直达（SPEC P1.5 #13）。
- **旅行必备**：停留倒计时、紧急求助、常用中国 App 收进同一个区块；“Your China apps”不再单独占一个区块。
- 行前阶段（before trip）只套用了新 token，结构未改，见“待解决”。

### Eat：拍照与选图分开，过敏原状态清晰
- 去掉 Photo / Type names 分段控件和虚线框，改为一张卡：**拍照**（主按钮，`capture="environment"` 直接开相机）+ **从相册选**（次按钮，不带 capture）+「输入菜名」文字链接；“翻译成”收成同一行的内联选择（只占所选语言的宽度）。
- 新增**过敏检查卡**：开启或关闭的状态、每个过敏原和饮食限制的标签（严重的用红色加“severe”）、检查范围说明（“菜单上每道菜都会检查主料、酱料和配料，按常见做法；各家厨房不同，严重过敏请同时出示过敏卡”），以及「编辑」「出示我的过敏卡」两个入口。
- 扫描结果顶部常驻一行“已检查：花生（严重）、甲壳类 · 编辑”，未设置时显示“未检查过敏原 · 开启”。
- 结果页的重拍按钮也分成三个：拍照 / 选图 / 输入；底部悬浮的过敏卡按钮从只有图标改为带文字“过敏卡”（有点单时只显示图标，给点单按钮让位）。
- 首次进入的过敏原弹窗底部补上 Safe Area，“保存”按钮不再贴着 Home 指示条。

### Explore：首屏只剩两行控件
- **之前**：城市胶囊行 → 搜索框 + Go → 分类胶囊 → “上海：精选”标题 → 看/吃分段 → 内容（五层，内容从约 300px 开始）。
- **之后**：①带城市范围的搜索栏（左侧城市按钮，右侧定位、清除；回车或键盘上的“搜索”提交，去掉了 Go 按钮）；②一行筛选：精选 · 必吃 · 博物馆 · 寺庙 · 公园 · 夜景 · 美食 · 购物。内容从约 165px 开始。
- 行程城市移到城市选择器顶部的“你的行程”一组，并标出当前城市。
- 修复：城市选择器的弹窗原本渲染在搜索 `<form>` 里，里面没写 type 的按钮会触发搜索提交，已把选择器移到表单外。窄屏（<360px）隐藏两个装饰图标，城市名和占位文字不再被截断。所有横向行改用 `.chip-row`，在 320 / 390 / 德语 / 深色下检测均无横向溢出。
- 页面实际在 Konsta 的 `.k-page` 里滚动，原来的 `window.scrollTo` 没有效果，已改为滚动 `.k-page`。

### Stay：先处理无结果
- 所有价位都没有精选（或接口失败）时，不再显示价位切换和一句灰字，改为 `EmptyState`：说明原因（只选确认能接待外宾的酒店，这个城市还没有），并给出三个下一步：**在 Trip.com 查看 {城市} 全部酒店**（金色，走 `goLink()` 追踪）、**看其他行程城市的精选**（例如上海）、**修改城市或日期**。
- 冗长的“我们如何挑选”收进 `Disclosure`（“我们如何挑选酒店”，含更新时间）。
- 护照登记提醒（入住提醒）和佣金披露保持常显。

### Talk：语言切换、输入、麦克风、结果操作
- 语言切换：两侧语言名和中间的交换按钮都能点，切换时会停止录音和朗读、清空输入。
- 输入区：卡片内无边框大输入框，带清除按钮，⌘/Ctrl+Enter 也能翻译；中文输入时使用中文字体。
- 麦克风：改为带文字的“说话”按钮；录音时变红并显示“停止”和“正在听…”，再点一下停止；处理 `onerror`，麦克风权限被拒时给出明确提示（原来没有 `onerror`）。
- 结果：**播放**（播放中变为“停止”，再点停止；如果浏览器不触发 `end` 事件，用轮询兜底，按钮不会一直停在“停止”）、**复制**（Clipboard API 被拒时改用 `execCommand`，显示“已复制” 2 秒）、**全屏**（主按钮；全屏卡的“这张卡写了什么”里显示你原本输入的话，常用语全屏则显示其译文）。

## 4. 仍待解决

1. **行前阶段的 Today** 没有按三层结构重排（这次只做了“在中国”阶段），只套用了 token。
2. **切换行程城市多了一步**：Explore 的行程城市从顶部一排胶囊改到城市选择器里（2 次点击），与 SPEC v0.5 #8 不一致。这是为了让内容提前出现做的取舍，可以观察使用情况；如果切换频繁，可以在搜索栏下加一个只在有 ≥2 个行程城市时出现的小切换。
3. **语音识别没有实测**：headless 浏览器和模拟器都无法测试麦克风输入；Capacitor 的 WKWebView 是否提供 `webkitSpeechRecognition` 需要在真机上确认，不支持的话需要原生插件。翻译后的自动朗读在 iOS 上可能因为不是用户手势触发而被系统静音，“播放”按钮不受影响。
4. **Dynamic Type**：字号 token 是 px，iOS 系统字体大小设置不会影响网页文字。这次用 320px 宽度近似测试了约 120% 的缩放；要真正支持 Dynamic Type，需要把字号 token 改为 rem 并跟随 `-apple-system-body`，这是独立的工作。
5. **大标题滚动折叠没了**：一级页面不再有 Konsta 的“滚动后大标题缩成导航栏标题”效果（为了省出 56px 做的取舍）。
6. **Stay 的区域列表**：有区域数据的城市（例如上海）三个区域加理由仍然较长，可以改成横向分段或胶囊选择。
7. **「从相册选」在 iOS 上仍会弹系统菜单**：网页 `<input type="file">` 不带 capture 时由系统决定，网页无法强制只开相册。
8. **没有运行 `npm run build`**（开发服务器在运行），没有 commit。前置截图里左下角的 Next 开发标记“N”是开发模式自带的，修改后的截图里已去掉。
9. 新增了 `china-travel-app/.claude/launch.json`（预览用的 dev server 配置）。
