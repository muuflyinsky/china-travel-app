# 补充餐厅照片：交给 AI 的提示词

**用法**

1. 跑一次匹配脚本，生成 `docs/reports/restaurant-no-photo.csv`：
   - 最好在 GitHub Actions 里运行 Restaurants；
   - 也可以本地运行 `node scripts/enrich-restaurants.mjs --report-only`，只生成报告，不调用高德。
2. 每次取 30–50 行，连同下面的提示词交给能上网的 AI（有浏览功能的 Claude、ChatGPT 等）。
3. 把 AI 返回的 CSV 合并保存，比如保存为 `filled.csv`。
4. 运行 `node scripts/enrich-restaurants.mjs --photos filled.csv` 导入。
   - 导入时脚本会检查来源。大众点评等不允许的来源、缺少来源页面、维基共享资源缺少作者或许可证的行，都会被拒绝，并在终端列出。
   - 配置了 Supabase 时，会同时写入数据库。
5. 抽查几行（打开 `source_page` 看一眼），再提交。

## 提示词（整段复制）

你是一名资料整理员，帮一个面向外国游客的中国旅行 App 给获奖餐厅（米其林、黑珍珠、大众点评必吃榜）补充照片。我会给你一张 CSV，每行是一家目前没有照片的餐厅。请逐行查找可以合法使用的照片，按要求填好 CSV 后返回。

### 只允许这三种来源

1. **高德地图**（amap.com 网页版或高德 App 上这家店的地点页）。
   - 照片地址通常是 `store.is.autonavi.com` 或 `aos-comment.amap.com` 开头。
   - `source` 填 `Amap`，`source_page` 填这家店在高德上的地点页网址。
   - 如果 CSV 里已有 `amap_id`，地点页是 `https://www.amap.com/place/<amap_id>`。
2. **维基共享资源**（commons.wikimedia.org）。
   - 只用许可证为 CC0、CC BY、CC BY-SA 或公有领域的图片。
   - `source` 填 `Wikimedia Commons / 作者名`，`license` 填许可证全称（例如 `CC BY-SA 4.0`），`source_page` 填文件页（`File:` 开头的页面）。
   - 图片地址用 `upload.wikimedia.org` 的直链。
   - 通常只有老字号或名店才有。
3. **餐厅官方渠道**（餐厅自己的官网），并且页面**明确允许媒体使用**（例如有“媒体资料下载”或“press kit”）。
   - `source` 填 `Official`，`source_page` 填那个页面，`notes` 写明许可依据。
   - 如果官网有照片但没写明允许使用，不要填图，只在 `notes` 写“官网有图，需联系授权”。

### 严禁的来源

以下来源的图片一律不要用，即使找到同一家店的图也不行：

- 大众点评、美团、小红书、携程或其他平台上的用户点评图片；
- 米其林指南官网和黑珍珠官网；
- 百度、谷歌、必应等搜索引擎的图片结果；
- 微博、抖音、Instagram、新闻网站、个人博客；
- 带其他平台水印的图片；
- 图库网站（Unsplash、Pexels、视觉中国等）；
- AI 生成的图片。

原因：这些图片的版权不属于我们，大众点评诉百度地图不正当竞争一案已有判例。

### 核对要求

- **必须是同一家店、同一家分店。** 店名括号里写了分店（例如“(新源南路)”）时，照片所在页面的地址要与分店对得上。CSV 里有 `address` 时，与它核对。对不上就留空。
- **照片内容**按优先级选：菜品特写 > 门面 > 店内环境。
- **不要用**以下照片：
  - 菜单、价目表、小票、发票；
  - 模糊或过暗的照片；
  - 能看清人脸的照片；
  - 有大面积文字广告的照片；
  - 与这家店无关的图。
- **每家最多 3 张**，按上面的优先级排列。`photo_url_1` 是最好的一张。
- **图片地址**必须是 https 开头、能直接打开的图片链接（以 .jpg、.png、.webp 结尾，或打开后直接显示图片），不能是网页地址。
- **找不到合规照片就留空，不要猜，不要用相似的店代替。**

### 输出格式

- 原样返回我给你的 CSV：列的顺序、表头和已有的内容都不要改，只填下面这几列：
  - `photo_url_1`、`photo_url_2`、`photo_url_3`
  - `source`、`license`、`source_page`、`checked`（填写今天的日期，格式 YYYY-MM-DD）、`notes`
- `notes` 用中文简短说明，例如“高德地点页地址与分店一致”“只找到门面照”“维基共享资源有图，但许可证为 CC BY-NC，不可用”。
- 只输出 CSV，放在一个代码块里，不要加其他文字。字段里有逗号时用英文双引号括起来。
- 最后在代码块外用一行写出统计：共 N 行，找到照片 X 行，留空 Y 行。
